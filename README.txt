❤️ STITCH LOVE WORLD — دليل الاستخدام ❤️
=========================================

ده المشروع بتاعك يا عمر. الملف الأساسي اللي فيه كل حاجة هو:

    index.html

ومعاه مجلد assets فيه 3 مجلدات فرعية لازم تحطي فيهم الملفات بنفسك:

    STITCH-LOVE-WORLD/
    │
    ├── index.html
    ├── README.txt
    │
    └── assets/
        ├── images/   → صور Stitch
        ├── audio/    → أغاني الخلفية
        └── voice/    → رسايلك الصوتية إنت

المشروع هيشتغل حتى لو المجلدات دي فاضية، بس الصور/الأغاني/الرسايل
مش هتظهر أو تتسمع لحد ما تحطيهم فيها.


1) أين أضع صور Stitch؟
------------------------
حطي 3 صور PNG لستيتش بالأسماء دي بالظبط جوه:

    assets/images/stitch_PNG13.png   (الوضع العادي)
    assets/images/stitch_PNG33.png   (فرحان / بيأشر)
    assets/images/stitch_PNG29.png   (بيرقص)

لو أي صورة ناقصة، الموقع مش هيبوظ ولا هيبين أيقونة "صورة مكسورة" —
هيظهر بدالها إيموجي 💙 بس عشان التجربة تفضل حلوة.


2) أين أضع الأغاني؟
---------------------
حطي ملفات الأغاني (mp3) جوه:

    assets/audio/

الأسماء المطلوبة (زي ما هي مكتوبة في ملف playlist.json):

    ihsasy-maak.mp3
    bahebak-ramy.mp3
    mesh-habibi-bas.mp3
    ayesh-ashanek.mp3
    asabaka-eshq.mp3


3) أين أضع الفويسات (رسايلك الصوتية)؟
----------------------------------------
حطي ملفات صوتك (mp3) جوه:

    assets/voice/

الأسماء المطلوبة (زي ما هي مكتوبة في ملف messages.json):

    message-01.mp3
    message-02.mp3
    message-03.mp3
    final-message.mp3

هتلاقي زرار 🎧 جنب باقي الأزرار تحت في الموقع، ده اللي بيفتح رسايلك دي.


4) كيف أضيف أغنية جديدة أو أغيّر واحدة؟ (الطريقة السهلة)
-------------------------------------------------------------
مش محتاجة تفتحي كود الموقع (index.html) خالص. افتحي بس الملف ده
بأي محرر نصوص (حتى Notepad كفاية):

    assets/audio/playlist.json

هتلاقيه شكله كده:

    [
      { "title": "اسم الأغنية", "file": "اسم-الملف.mp3" },
      { "title": "اسم أغنية تانية", "file": "ملف-تاني.mp3" }
    ]

انسخي سطر { "title": ..., "file": ... } وحطي مكانه اسم الأغنية
الجديدة واسم ملف الـ mp3 (بعد ما تحطيه في مجلد assets/audio)،
واحطي فاصلة (,) بعد آخر سطر قبل اللي زودتيه. احفظي الملف بس،
مفيش داعي تلمسي index.html خالص.

⚠️ الطريقة دي شغالة بس لما الموقع يكون متفتح من رابط حقيقي
(https:// أو من سيرفر محلي) — شوفي بند "كيف أشغل المشروع" تحت.
لو فتحتي index.html مباشرة من ملفات الجهاز (file://)، المتصفح
بيمنع قراءة ملف playlist.json، فالموقع هيرجع تلقائيًا للأغاني
الأساسية المكتوبة جوه الكود، من غير ما يبوظ أي حاجة.


5) كيف أضيف رسالة صوتية جديدة مني؟ (الطريقة السهلة)
---------------------------------------------------------
بنفس الطريقة بالظبط، بس افتحي:

    assets/voice/messages.json

وزوّدي سطر جديد بنفس الشكل:

    { "label": "اسم الرسالة", "file": "اسم-الملف.mp3", "intro": "جملة Stitch قبل ما يشغلها" }

وحطي ملف الصوت (mp3) في assets/voice.


6) طريقة متقدمة (اختيارية)
------------------------------
لو حابب تعدّل من جوه الكود نفسه بدل ملفات الـ json، لسه ممكن —
افتحي index.html ودوري (Ctrl+F) على:

    AUDIO_CONFIG              (قايمة الأغاني الأساسية)
    OMAR_VOICE_MESSAGES       (قايمة رسايلك الصوتية الأساسية)

القايمتين دول هما "النسخة الاحتياطية" اللي الموقع بيستخدمها لو
ملفات playlist.json / messages.json مش موجودة أو مش متاحة.


7) كيف أشغل المشروع؟
-----------------------
أسهل طريقة: ارفعي مجلد STITCH-LOVE-WORLD كامل (بكل اللي جواه) على
أي استضافة بسيطة ومجانية بتدعم HTTPS، زي:
    - GitHub Pages
    - Netlify (اسحبي المجلد وارميه في الموقع بس)
    - Vercel

أو شغّليه محليًا على جهازك بأي "local server" بسيط (مش بمجرد فتح
الملف من الفولدر مباشرة، عشان بعض المميزات زي التسجيل الصوتي
وملفات playlist.json/messages.json محتاجة سيرفر حقيقي مش file://).


8) ليه التسجيل الصوتي محتاج HTTPS؟
--------------------------------------
المتصفحات (كروم / سفاري / إلخ) بتمنع أي موقع من استخدام المايكروفون
إلا لو الموقع مفتوح من رابط آمن يبدأ بـ https:// — أو من جهازك مباشرة
عن طريق localhost. ده إجراء أمان من المتصفح نفسه مش حاجة من عندنا،
وده بيحصل مع أي موقع في الدنيا مش بس ده.

مهم جدًا: لو فتحتي index.html مباشرة من مدير الملفات في التابلت أو
الموبايل (يعني بتدوسي على الملف نفسه وبيتفتح برابط بيبدأ بـ file://)،
زرار التسجيل مش هيشتغل أبدًا، حتى لو الكود والزرار سليمين 100% —
ده قيد من المتصفح نفسه ومفيش كود ممكن يتخطاه. الموقع هيبين لها
رسالة واضحة بالعربي بتقولها السبب بالظبط.

الحل الوحيد: ارفعي الموقع على استضافة بتدّي رابط https تلقائي
(زي Netlify أو Vercel أو GitHub Pages) وافتحيه من هناك — وقتها
التسجيل هيشتغل عادي تمامًا.


9) Firebase (تخزين الرسايل والتسجيلات)
------------------------------------------
لو مش حابب تربط Firebase، الموقع شغال برضه في "وضع تجربة" —
كل حاجة (الرسايل، الإجابات، التسجيلات) بتتخزن على جهاز اللي بتفتح
الموقع بس (localStorage)، ومش بتترفع لأي سيرفر.

لو حابب تربطه بمشروع Firebase حقيقي، افتحي index.html ودوري على:

    const firebaseConfig = {

وحطي بيانات مشروعك (من Firebase Console → Project settings → SDK setup)
بدل القيم اللي مكتوب فيها YOUR_...
